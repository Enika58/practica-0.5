# АИС Справочная служба

Автоматизированная информационная система для справочной службы, обеспечивающая эффективное управление информацией, повышение качества обслуживания клиентов и оптимизацию работы персонала.

## Возможности системы

### Управление запросами
- Создание и отслеживание запросов клиентов
- Классификация по категориям и типам услуг
- Назначение исполнителей
- Приоритизация (низкий, средний, высокий, критический)
- Отслеживание статусов (новый, в работе, на паузе, решён, закрыт, отклонён)
- Комментарии и история изменений

### Справочная информация
- Иерархические категории
- Элементы справочника с поиском по ключевым словам
- FAQ (часто задаваемые вопросы)
- Типы услуг с параметрами

### Аутентификация и авторизация
- Система пользователей с ролями (admin, manager, operator)
- Блокировка аккаунта при неудачных попытках входа
- Профиль пользователя
- Управление пользователями

### Отчётность и аналитика
- Панель управления с основной статистикой
- Статистика по статусам, приоритетам, категориям
- Статистика по исполнителям
- Экспорт данных в CSV
- Тренды за период

### Поиск
- Глобальный поиск по справочнику и запросам
- Поиск по категориям и тегам
- Поиск в FAQ

## Технологии

- **Backend**: Python 3.9+, Flask
- **Database**: SQLite (по умолчанию), поддержка PostgreSQL
- **Frontend**: Bootstrap 5, HTML5, CSS3, JavaScript
- **Аутентификация**: Flask-Login
- **ORM**: SQLAlchemy

## Установка

### 1. Клонирование репозитория

```bash
cd ais-spravka
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
venv\Scripts\activate  # Windows
# или
source venv/bin/activate  # Linux/Mac
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка

Скопируйте `.env` и настройте параметры:

```bash
copy .env .env.local  # Windows
# или
cp .env .env.local    # Linux/Mac
```

### 5. Запуск

```bash
python run.py
```

Система доступна по адресу: http://localhost:5000

## Первоначальный вход

По умолчанию создаётся администратор:
- **Логин**: admin
- **Пароль**: admin123

> ⚠️ Обязательно измените пароль после первого входа!

## Роли пользователей

| Роль | Описание | Возможности |
|------|----------|-------------|
| **Admin** | Администратор | Полный доступ, управление пользователями |
| **Manager** | Менеджер | Управление запросами, просмотр отчётов |
| **Operator** | Оператор | Работа с запросами, справочник |

## API Endpoints

### Справочники
- `GET /api/directories/categories` - Список категорий
- `GET /api/directories/items` - Поиск элементов
- `GET /api/faq` - Список FAQ
- `GET /api/faq/search` - Поиск в FAQ

### Запросы
- `GET /api/requests/<id>/comments` - Комментарии запроса

### Статистика
- `GET /api/stats/requests-by-status` - По статусам
- `GET /api/stats/requests-by-priority` - По приоритетам
- `GET /api/stats/trending` - Тренды

## Безопасность

- Хеширование паролей (SHA-256)
- Защита от CSRF
- Блокировка аккаунтов
- Ролевой доступ
- Валидация всех входных данных
